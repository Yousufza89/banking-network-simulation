# Banking Network Simulation - Cisco Packet Tracer

## 📌 Description
This project simulates the internal and inter-branch networking of a banking system using Cisco Packet Tracer. Focuses on secure and efficient connectivity between HQ, branches, and ATMs.

## 🏛 Architecture Includes:
- Head Office, Branches, and ATM Nodes
- Routers, Switches, and End Devices
- Static & Dynamic Routing (RIP, OSPF)
- VLANs, DHCP, NAT Configuration
- Security Configurations (ACLs)

## 🛠 Tools Used
- Cisco Packet Tracer 8.x

## 🧠 Learning Outcomes
- Enterprise-level topology design
- Routing and switching protocols
- Access control and subnetting
